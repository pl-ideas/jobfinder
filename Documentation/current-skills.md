# Job Matching Guidance

Future job-matching functionality should evaluate positions holistically.

Do not require every skill to appear in a job description.

A position can be a strong match when its core technology stack and responsibilities substantially overlap with the Primary Skills.

For example:

`Senior Full Stack Engineer — C# / .NET / React / Azure`

should be considered a very strong match even if the position does not mention:

* Next.js
* Angular
* PingOne
* Docker
* Kubernetes

Likewise, specialized skills should increase the relevance of a position when present but generally should not be mandatory unless the position itself is specialized.

Job matching should distinguish between:

* Required skills
* Preferred skills
* Matching skills
* Missing skills
* Transferable/related skills

Do not automatically reject an otherwise strong position because one or more preferred technologies are absent.
